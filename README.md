# JS Mini Games Portfolio

A small portfolio demo built with plain HTML, CSS, and JavaScript only.

## Included
- Scratch card using Canvas API + Pointer Events
- Prize spinner using Math.random() + CSS transforms/transitions
- Quiz using DOM events and JavaScript state

## Run locally
Open `index.html` in a browser.

## Deployment
This repository includes a tiny dependency-free Node static server (`server.js`) so it can deploy directly to Railway with `npm start`. The browser experience itself remains plain HTML, CSS, and JavaScript.

For GitHub Pages:
1. Create a new GitHub repository.
2. Upload `index.html`, `styles.css`, and `app.js`.
3. Open Settings → Pages.
4. Deploy from your main branch/root.
5. Use the generated GitHub Pages URL in your application.
